PRAKTIK KEAMANAN JARINGAN - SESI 3 (FISIK)

Konfigurasi Hotspot & Manajemen Bandwidth Menggunakan MikroTik

Pengajar: Jauhari Saputra | Mata Pelajaran: Keamanan Jaringan

> SKENARIO SESI 3 (ALAT FISIK)

Anda bertugas mengelola jaringan publik di sekolah. Anda diminta membangun sebuah sistem autentikasi (Login Page) agar tidak sembarang orang bisa mengakses internet. Setelah klien berhasil login, Anda harus membatasi kecepatan maksimal (Bandwidth) mereka menggunakan Simple Queue agar koneksi tetap stabil untuk semua orang.

Gunakan topologi fisik yang sama: Port Ether1 ke internet sekolah, dan Ether2 ke PC Klien.

> A. IDENTITAS PESERTA DIDIK

> PRAKTIK 1: MEMBUAT SERVER HOTSPOT

Langkah Kerja:

  1. Pastikan IP Address pada ether2 MikroTik sudah diatur (Contoh: 192.168.10.1/24).
  2. Di Winbox, buka menu IP > Hotspot.
  3. Pilih tab Servers, lalu klik tombol Hotspot Setup.
  4. Hotspot Interface: Pilih ether2 (yang mengarah ke PC). Klik Next.
  5. Local Address of Network: Biarkan default (pastikan 'Masquerade Network' tercentang). Klik Next.
  6. Address Pool & Certificate: Klik Next terus hingga sampai pada DNS Name.
  7. DNS Name: Isi dengan domain lokal, contoh: sekolah.net. Klik Next.
  8. Name of Local Hotspot User: siswa. Password for the user: 123. Klik Next sampai sukses.

> PRAKTIK 2: KONFIGURASI MANAJEMEN BANDWIDTH (SIMPLE QUEUE)

Langkah Kerja:

  1. Untuk menghindari klien mengunduh file besar yang membuat jaringan melambat, kita batasi kecepatannya.
  2. Buka menu Queues di Winbox, lalu pilih tab Simple Queues.
  3. Klik tombol Tambah (+).
  4. Name: Batas-Klien. Target: 192.168.10.0/24 (Isi dengan segmen IP ether2 Anda).
  5. Target Upload (Max Limit): Pilih 2M.
  6. Target Download (Max Limit): Pilih 2M.
  7. Klik Apply, lalu OK. Warnanya mungkin akan menjadi kuning/merah saat bandwidth penuh.

> PRAKTIK 3: PENGUJIAN DAN ANALISIS

Langkah Kerja Pengujian:

  1. Jika browser Anda tiba-tiba kehilangan koneksi internet, itu adalah hal wajar.
  2. Buka browser PC, ketikkan nama DNS Anda di URL Bar, contoh: http://sekolah.net.
  3. Halaman Login MikroTik akan muncul. Masukkan username: siswa dan password: 123.
  4. Setelah berhasil masuk, buka tab baru dan jalankan Speedtest (speedtest.net atau fast.com).
  5. Pastikan kecepatan unduh (download) dan unggah (upload) terhenti/tercekik di angka maksimal 2 Mbps.
