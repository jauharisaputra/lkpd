> DICTIONARY / GLOSARIUM_

Kamus istilah teknis Keamanan Jaringan dan MikroTik.

MAC Address (Media Access Control)
Alamat fisik unik yang tertanam pada antarmuka jaringan (NIC) suatu perangkat sejak dari pabrik. Berfungsi sebagai identitas permanen perangkat di lapisan Data Link.
DHCP (Dynamic Host Configuration Protocol)
Protokol jaringan yang secara otomatis meminjamkan dan memberikan IP Address serta konfigurasi jaringan lainnya kepada perangkat (klien) yang terhubung.
Winbox
Utilitas (software) kecil berbasis Windows yang digunakan untuk mengkonfigurasi dan mengelola sistem operasi MikroTik RouterOS melalui antarmuka grafis (GUI).
NAT (Network Address Translation) - Masquerade
Metode untuk memetakan alamat IP lokal (private) menjadi satu alamat IP publik sehingga komputer di jaringan lokal dapat terhubung ke internet.
Web Proxy
Server yang bertindak sebagai perantara untuk menerima permintaan akses web dari pengguna. Pada MikroTik, sering digunakan untuk memblokir situs tertentu atau caching.
