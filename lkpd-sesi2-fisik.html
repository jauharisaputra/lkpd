PRAKTIK KEAMANAN JARINGAN - SESI 2 (FISIK)

Konfigurasi Web Proxy & Filtering Menggunakan RouterBoard MikroTik

Pengajar: Jauhari Saputra | Mata Pelajaran: Keamanan Jaringan

> SKENARIO SESI 2 (ALAT FISIK)

Gunakan topologi fisik yang sama seperti Sesi 1 (Ether1 ke Internet, Ether2 ke PC Klien). Setelah berhasil mendistribusikan koneksi internet ke Klien PC Anda, amankan lalu lintas *web* klien. Aktifkan fitur Web Proxy di router MikroTik dan lakukan *Transparent Proxy* sehingga browser PC klien otomatis terfilter tanpa perlu setting manual.

Anda akan melakukan pemblokiran terhadap:
1. Situs web tertentu (Contoh: linux.or.id)
2. Ekstensi file spesifik (Contoh: .mp3 / .mkv)

> A. IDENTITAS PESERTA DIDIK

> PRAKTIK 1: MENGAKTIFKAN WEB PROXY

Langkah Kerja:

  1. Buka Winbox di PC Anda, hubungkan ke RouterBoard fisik Anda. Pastikan RouterBoard sudah mendistribusikan Internet ke PC dengan baik.
  2. Buka menu IP > Web Proxy.
  3. Centang kotak Enable.
  4. Biarkan Port pada angka 8080.
  5. Ubah Cache Administrator dengan nama_kelompok@sekolah.sch.id.
  6. Klik Apply lalu OK.

> PRAKTIK 2: MEMBUAT TRANSPARENT PROXY (NAT)

Langkah Kerja:

  1. Agar klien PC tidak perlu mensetting proxy di browser mereka, kita alihkan trafik HTTP secara otomatis.
  2. Buka menu IP > Firewall > NAT, klik (+).
  3. General: Chain = dstnat | Protocol = 6 (tcp) | Dst. Port = 80.
  4. Action: Action = redirect | To Ports = 8080.
  5. Klik Apply, OK.

> PRAKTIK 3: BLOKIR SITUS (DOMAIN)

Langkah Kerja:

  1. Buka menu IP > Web Proxy > Access, klik (+).
  2. Kosongkan bagian lain, cukup isi Dst. Host: *linux.or.id* (Gunakan tanda bintang agar mencakup seluruh sub-domain).
  3. Ubah Action menjadi deny. Klik Apply & OK.

> PRAKTIK 4: BLOKIR EKSTENSI FILE

Langkah Kerja:

  1. Buka menu IP > Web Proxy > Access, klik (+) untuk buat rule baru.
  2. Kali ini kosongkan Dst. Host. Isi pada bagian Path: *.mp3*.
  3. Ubah Action menjadi deny. Klik Apply & OK.
  4. Lakukan hal yang sama jika ingin menambah rule blokir file *.mkv* atau *.iso*.

> PRAKTIK 5: PENGUJIAN DAN ANALISIS

Langkah Kerja Pengujian:

  1. Buka browser di PC Anda.
  2. Ketik alamat http://linux.or.id (Pastikan http, BUKAN https).
  3. Coba cari dan download file bertipe .mp3 di internet menggunakan HTTP.
  4. Jika muncul halaman "ERROR: Forbidden" dan terdapat email Cache Administrator Anda di bawahnya, artinya sukses!
