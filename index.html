LEMBAR KERJA PESERTA DIDIK (LKPD)

PRAKTIK KEAMANAN JARINGAN - SESI 1

Simulasi Firewall Filtering Menggunakan MikroTik RouterOS dan VirtualBox

Pengajar: Jauhari Saputra | Mata Pelajaran: Keamanan Jaringan

> D. SKENARIO DAN TOPOLOGI

Anda bertugas sebagai administrator jaringan laboratorium. Buat 1 router MikroTik dan 1 klien Windows dalam lingkungan virtual. Router akan dikonfigurasi untuk bereksperimen dengan penyaringan (filtering) string .exe dan .bat.

Topologi Jaringan:
- MikroTik Adapter 1: Bridged Adapter (Terhubung ke internet/host)
- MikroTik Adapter 2: Internal Network bernama intnet
- Windows Klien Adapter 1: Internal Network bernama intnet

> A. IDENTITAS PESERTA DIDIK

> PRAKTIK 1: PERSIAPAN FILE

Langkah Kerja Persiapan:

  1. Unduh dan pasang aplikasi VirtualBox di komputer Anda dari https://www.virtualbox.org/.
  2. Unduh file ISO MikroTik RouterOS dari https://mikrotik.com/download (Pilih paket x86).
  3. Unduh aplikasi Winbox 64-bit dari situs resmi MikroTik.
  4. Siapkan file ISO Windows (Gunakan versi berlisensi sesuai spesifikasi komputer).
  5. Buat satu folder khusus di komputer Anda, lalu masukkan keempat file di atas ke dalam folder tersebut agar rapi.

> PRAKTIK 2: INSTALASI MIKROTIK VIRTUAL

Langkah Kerja Instalasi MikroTik:

  1. Buka VirtualBox, klik New, beri nama mesin: MikroTik.
  2. Pilih Type: Linux dan Version: Other Linux (64-bit). Atur RAM menjadi 256 MB. Buat virtual hard disk secukupnya.
  3. Pilih mesin MikroTik, klik Settings -> Storage. Masukkan ISO MikroTik yang tadi Anda unduh ke gambar CD kosong.
  4. Klik Settings -> Network. Aktifkan Adapter 1 dan pilih Bridged Adapter. Aktifkan Adapter 2 dan pilih Internal Network, lalu beri nama intnet.
  5. Klik Start (Nyalakan VM). Pada layar hitam berbayang (instalasi), tekan huruf a di keyboard untuk memilih semua paket, lalu tekan i untuk menginstal.
  6. Jika ditanya keep old configuration, tekan n. Jika ditanya continue, tekan y.
  7. Setelah selesai dan muncul tulisan "Press ENTER to reboot", JANGAN tekan enter! Matikan mesin paksa dengan klik tanda silang jendela VM lalu pilih Power off the machine.
  8. Masuk lagi ke Settings -> Storage, keluarkan (Remove) ISO MikroTik dari optical drive. Lalu nyalakan kembali mesinnya.
  9. Saat diminta login, ketik admin lalu tekan Enter. Untuk Password, kosongkan saja dan tekan Enter.

> PRAKTIK 3: INSTALASI WINDOWS KLIEN

Langkah Kerja Instalasi Windows:

  1. Buat VM baru di VirtualBox untuk Windows. Lakukan instalasi Windows seperti biasa menggunakan ISO Windows yang disiapkan.
  2. Pada pengaturan VM Windows, buka Settings -> Network. Aktifkan Adapter 1 saja, pilih Internal Network, lalu beri nama intnet (harus sama persis dengan pengaturan MikroTik).
  3. Pindahkan file aplikasi Winbox yang sudah didownload dari komputer asli Anda ke dalam VM Windows (Bisa pakai Shared Folder Virtualbox atau Drag & Drop).

> PRAKTIK 4: AKSES VIA WINBOX

Langkah Kerja Akses Winbox:

  1. Pastikan VM MikroTik dan VM Windows Klien Anda menyala dua-duanya.
  2. Di dalam VM Windows, jalankan aplikasi Winbox.
  3. Pilih tab Neighbors dan tunggu hingga nama perangkat MikroTik muncul di daftar.
  4. Klik pada teks MAC Address MikroTik yang muncul.
  5. Isi kotak Login dengan admin dan biarkan kotak Password kosong. Klik tombol Connect.

> PRAKTIK 5: KONFIGURASI FIREWALL FILTER RULES

Langkah Kerja Blokir File (.exe dan .bat):

  1. Di dalam Winbox, klik menu IP di sebelah kiri, lalu pilih Firewall.
  2. Pilih tab Filter Rules (paling kiri atas), lalu klik tombol tanda Tambah (+) warna biru.
  3. Aturan Pertama (.exe): Pada tab General, pastikan Chain terisi forward. Klik tab Advanced, isi kolom Content dengan .exe. Klik tab Action, ubah opsi menjadi drop. Klik Apply lalu OK.
  4. Aturan Kedua (.bat): Ulangi langkah no 2 di atas. General -> Chain = forward. Advanced -> Content = .bat. Action -> Action = drop. Klik Apply lalu OK.

> PRAKTIK 6: PENGUJIAN DAN ANALISIS

Langkah Kerja Pengujian:

  1. Buka browser di dalam VM Windows Klien.
  2. Gunakan jaringan sekolah yang diizinkan untuk mencari/mendownload sembarang file berakhiran .exe (misal file instalasi ringan) secara HTTP (tanpa huruf 's').
  3. Coba juga download file berakhiran .bat.
  4. Amati di jendela Winbox MikroTik Anda pada bagian Filter Rules. Perhatikan angka pada kolom Bytes / Packets (Counter). Apakah angkanya bertambah jalan saat file mencoba di-download?

> PRAKTIK 7: PEMECAHAN MASALAH

Bantuan Masalah (Troubleshooting):

- Jika MikroTik tidak muncul di Neighbors: Pastikan VM MikroTik menyala, Adapter 2 aktif, dan namanya persis 'intnet'.
- Jika Windows tak ada koneksi: Cek IP, gateway, dan routing.
- Jika Winbox gagal login: Pastikan klik MAC Address, bukan IP Address. User 'admin' password kosong.
