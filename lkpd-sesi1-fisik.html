PRAKTIK KEAMANAN JARINGAN - SESI 1 (PERANGKAT FISIK)

Konfigurasi Dasar & Firewall Filtering Menggunakan RouterBoard MikroTik

Pengajar: Jauhari Saputra | Mata Pelajaran: Keamanan Jaringan

> D. SKENARIO DAN TOPOLOGI FISIK

Anda bertugas sebagai administrator jaringan laboratorium. Praktik ini menggunakan Router fisik (RouterBoard) dan PC/Laptop nyata.

Pengkabelan (Topologi):
- Port Ether1 MikroTik: Dihubungkan ke sumber Internet (Modem/ISP/Switch Sekolah) menggunakan kabel UTP.
- Port Ether2 MikroTik: Dihubungkan ke port LAN PC/Laptop Anda menggunakan kabel UTP.

> A. IDENTITAS PESERTA DIDIK

> PRAKTIK 1: PENGKABELAN & AKSES AWAL

Langkah Kerja:

  1. Siapkan alat fisik: RouterBoard MikroTik, Adaptor daya, 2 buah Kabel UTP (LAN), dan PC/Laptop Klien.
  2. Colokkan kabel internet dari sekolah ke port Ether1 pada MikroTik.
  3. Colokkan ujung kabel LAN kedua ke port Ether2 MikroTik, dan ujung satunya ke PC/Laptop Anda.
  4. Nyalakan MikroTik, buka aplikasi Winbox 64-bit di PC Anda.
  5. Masuk ke tab Neighbors, klik MAC Address MikroTik yang muncul, login dengan user admin (password kosong), lalu Connect.
  6. Jika router bekas pakai, reset dengan cara buka menu System > Reset Configuration, centang No Default Configuration, lalu klik Reset Configuration. Login kembali setelah router menyala.

> PRAKTIK 2: KONFIGURASI DASAR INTERNET

Langkah Kerja (Membagikan Internet ke PC):

  1. Internet Router: Buka IP > DHCP Client > Klik (+) > Pilih Interface ether1 > Apply > OK. (Pastikan statusnya bound).
  2. IP Lokal: Buka IP > Addresses > Klik (+) > Isi Address 192.168.10.1/24 > Pilih Interface ether2 > Apply > OK.
  3. DHCP untuk PC: Buka IP > DHCP Server > Klik tombol DHCP Setup > Pilih Interface ether2 > Klik Next terus hingga sukses.
  4. NAT (Sangat Penting): Buka IP > Firewall > Tab NAT > Klik (+).
    - Tab General: Chain = srcnat, Out. Interface = ether1
    - Tab Action: Action = masquerade. Klik Apply > OK.
  5. Cek koneksi internet di browser PC Anda. Jika gagal, cabut-pasang kabel LAN di PC agar mendapat IP otomatis.

> PRAKTIK 3: KONFIGURASI FIREWALL FILTER RULES

Langkah Kerja Blokir File (.exe dan .bat):

  1. Buka menu IP > Firewall, lalu pilih tab Filter Rules. Klik tanda (+).
  2. Aturan .exe: Tab General -> Chain = forward. Tab Advanced -> Content = .exe. Tab Action -> Action = drop. Klik Apply, OK.
  3. Aturan .bat: Ulangi langkah di atas, namun isi Content dengan .bat. Klik Apply, OK.

> PRAKTIK 4: PENGUJIAN DAN ANALISIS

Langkah Kerja Pengujian:

  1. Gunakan browser di PC Anda untuk mendownload file berakhiran .exe (Usahakan via HTTP).
  2. Coba juga download file script berakhiran .bat.
  3. Amati kolom Bytes / Packets (Counter) pada aturan Filter Rules di Winbox saat download berlangsung.
