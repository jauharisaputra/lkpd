PRAKTIK KEAMANAN JARINGAN - SESI 3

Membangun Sistem Autentikasi User (Hotspot) & Manajemen Bandwidth

Pengajar: Jauhari Saputra | Mata Pelajaran: Keamanan Jaringan

> SKENARIO SESI 3

Anda ditugaskan merancang jaringan publik sekolah. Untuk mencegah akses tidak sah dan monopoli kecepatan internet, Anda harus mengaktifkan sistem Captive Portal (Hotspot) yang mewajibkan pengguna login, serta membatasi kecepatan internet klien menggunakan Simple Queue.

> A. IDENTITAS PESERTA DIDIK

> PRAKTIK 1: KONFIGURASI HOTSPOT SETUP

Langkah Kerja:

  1. Buka menu IP > Hotspot di Winbox, masuk ke tab Servers.
  2. Klik tombol Hotspot Setup.
  3. Pilih interface lokal yang terhubung ke klien Windows (Adapter 2 / intnet).
  4. Ikuti instruksi Next, atur rentang IP, dan masukkan DNS Name (contoh: login.sekolah.sch.id).
  5. Selesaikan setup hingga muncul pesan Setup has completed successfully.

> PRAKTIK 2: MANAJEMEN USER PROFILE & PENGGUNA

Langkah Kerja:

  1. Pindah ke tab User Profiles. Klik (+) untuk membuat profil baru (misal: Profil-Siswa).
  2. Pada tab Users, klik (+) untuk membuat user baru.
  3. Isi Name (username) dan Password, lalu pilih Profile yang baru Anda buat. Klik OK.

> PRAKTIK 3: PENGUJIAN LOGIN HOTSPOT

Langkah Kerja:

  1. Buka browser di Windows Klien.
  2. Akses situs sembarang (HTTP), atau ketik DNS Name yang Anda atur sebelumnya.
  3. Halaman login MikroTik akan muncul. Masukkan Username dan Password yang telah dibuat.

> PRAKTIK 4: LIMITASI BANDWIDTH (SIMPLE QUEUE)

Langkah Kerja:

  1. Buka menu Queues, pada tab Simple Queues klik (+).
  2. Isi Name (contoh: Limit-Klien).
  3. Pada Target, arahkan ke IP Address atau Interface klien Windows Anda.
  4. Pada bagian Max Limit, atur Target Upload (misal: 512k) dan Target Download (misal: 1M). Klik OK.
